# Product: To-Do List Life Dashboard

A client-side personal productivity dashboard built as a static web application.

## Purpose

Help users stay focused and organised throughout their day by combining a live greeting, a Pomodoro focus timer, a to-do list, and quick-access website links — all in a single browser tab.

## Target Users

Beginners and students learning web development. The codebase is intentionally simple and readable.

## Key Features

- **Greeting** — displays the user's name, current time, current date, and a time-of-day greeting (Good Morning / Afternoon / Evening).
- **Focus Timer** — a Pomodoro countdown timer with selectable durations (15, 25, 30, 45 minutes), Start / Stop / Reset controls, and a completion notification.
- **To-Do List** — add, edit, complete, and delete tasks; completed tasks are visually distinguished.
- **Quick Links** — save and open favourite website URLs with a single click.
- **Light / Dark Mode** — toggleable theme with persistent preference.
- **Custom Name** — user enters their name once; it appears in the greeting on every visit.

## Assignment Context

This project was built for **CodingCamp-24August26-Phytia** as an MVP demonstration of HTML, CSS, and Vanilla JavaScript skills without any external frameworks or backend.
